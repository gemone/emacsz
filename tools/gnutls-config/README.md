# gnutls-config: GnuTLS/nettle configure-generated artifacts

This directory pins the configure-generated headers that GnuTLS 3.8.13 and
nettle 3.10.2 normally produce with autotools.  They are committed so
`zig build` can compile both libraries with `zig cc` alone (no autotools,
no `make`, no shell probes).

## Sources

- `config.h` - GnuTLS configure result for aarch64-apple-darwin, minimal
  feature set (see the configure flags below).
- `gnutls/gnutls.h` - generated from `lib/includes/gnutls/gnutls.h.in`.
- `gl/*.h` (incl. `arpa/`, `sys/`, `malloc/`) - gnulib replacement
  headers generated in GnuTLS's `gl/` build dir.
- `unistring/*.h` (incl. `sys/`) - generated libunistring headers from
  GnuTLS's `lib/unistring/` build dir (`unictype.h`, `uninorm.h`,
  `unistr.h`, `unitypes.h`, `limits.h`, `stdint.h`, `sys/types.h`).
- `nettle/config.h` / `nettle/version.h` - nettle configure results.
- `nettle/ecc-*.h` - headers generated by nettle's `eccdata` tool.
- `nettle/nettle/*.h` - nettle's public headers as installed under
  `include/nettle` (all tarball headers; the reference build's
  `NETTLE_CFLAGS=-I<prefix>/include` resolved GnuTLS's `<nettle/...>`
  includes against these).
- `nettle-sources.txt`, `gnutls-sources.txt`,
  `gnutls-unistring-sources.txt` - the exact C file lists the reference
  build compiled (used by build.zig via `@embedFile`).

## How they were regenerated

Reference build on macOS (aarch64), compiler `CC="zig cc"`:

```
# nettle 3.10.2 (pure C, no assembler, mini-gmp instead of GMP)
./configure --prefix=/tmp/ref-prefix --enable-mini-gmp --disable-shared \
  --enable-static --disable-documentation --disable-assembler

# GnuTLS 3.8.13 against the nettle prefix above
PKG_CONFIG_PATH=/tmp/ref-prefix/lib/pkgconfig CC="zig cc" CFLAGS="-O2" \
./configure --prefix=/tmp/ref-prefix --enable-static --disable-shared \
  --with-nettle-mini --with-included-unistring --with-included-libtasn1 \
  --without-idn --without-p11-kit --without-tpm --without-tpm2 \
  --without-zlib --without-brotli --without-zstd --disable-gost \
  --disable-doc --disable-tests --disable-tools --disable-cxx \
  --disable-nls --disable-libdane --disable-hardware-acceleration \
  --disable-dtls-srtp-support --disable-ocsp
```

The generated headers (and the `make`-derived source lists) were copied
from the build tree.  Bumping GnuTLS/nettle versions or porting to a new
OS means re-running this reference build and updating these files.
